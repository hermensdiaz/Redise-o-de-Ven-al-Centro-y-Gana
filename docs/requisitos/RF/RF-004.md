# RF-004 | Registro de participación 

El sistema permite ingresar un número de teléfono 10 dígitos y consulta en la base de datos en tiempo real para determinar si el concursante es usuario de primer ingreso o usuario ya registrado. 

### Objetivo 

Identificar el estado del concursante en el sistema a partir de su número de telefónico. 

### Alcance  

Captura del número, validación de formato (10 dígitos numéricos) y consulta inmediata en la base de datos 

### Actores 

El Concursante (Cliente que participa en la dinámica). 

### Precondiciones 

El concursante presionó el botón comenzar en la pantalla de inicio.  

### Postcondiciones 

Si el número ya existe: El sistema notifica que el usuario está registrado y lo dirige a la fase de datos de la compra. 

Si el número NO existe: El sistema despliega el mensaje emergente informativo para nuevos usuarios y habilita el formulario de registro de datos personales (RF-005) 

### Flujo Principal 

El sistema presenta el campo de captura para ingresar el número telefónico de 10 dígitos. 

El concursante digita su número telefónico y presiona el botón "Verificar". 

El sistema consulta la base de datos y determina que el número no se encuentra registrado. 

El sistema despliega una ventana emergente (popup) con un mensaje de bienvenida para nuevos usuarios. 

El concursante presiona "Continuar" y el sistema lo redirige al formulario de captura de datos personales (RF-005) 

### Flujo alterno 

A1. El concursante no ingresa ningún dato. 

El sistema detecta que la casilla se encuentra vacía. 

El sistema muestra el mensaje: "Campo obligatorio". 

A2. El concursante ingresa un número inferior a 10 dígitos. 

El sistema detecta que el número ingresado no es válido 

El sistema muestra el mensaje: "Número inválido" 

A3. El concursante ingresa un número superior a 10 dígitos. 

El sistema detecta que el número ingresado no es válido 

El sistema muestra el mensaje: "Número inválido"

### Justificación 

Justificación: permite conocer si el número telefónico ya ha sido registrado.
