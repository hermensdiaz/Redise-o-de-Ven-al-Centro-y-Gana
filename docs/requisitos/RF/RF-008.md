# RF-008 | Registro de participación

El sistema debe permitir al usuario consultar y aceptar los Avisos de Privacidad, mediante un enlace que abre el documento en una nueva pestaña

### Objetivo

Proporcionar transparencia legal al concursante, para que conozca como trataran sus datos personales antes de aceptarlos.

### Alcance 

Cubre el enlace “avisos de privacidad” presente en el formulario de registro de datos personales, incluye la apertura del documento en una nueva pantalla.

### Actores 

El Concursante (Cliente que participa en la dinámica).
Precondiciones

El concursante ha ingresado a la página web de la compaña mediante el enlace o QR, y ha comenzado su registro como usuario nuevo y abre el enlace de “avisos de privacidad” que está visible en pantalla.

### Postcondiciones

El documento de Avisos de Privacidad queda visible en una nueva pantalla y el concursante puede regresar a la página web para continuar con su registro.

# Flujo Principal

1.	El concursante presiona el encale “avisos de privacidad”.

2.	El sistema abre una nueva pantalla con el documento de Avisos de Privacidad.

3.	El concursante lee el documento.

4.	El concursante cierra la pantalla y regresa fase de registro como usuario nuevo.

5.	El concursante aceptar los Avisos de Privacidad.

# Flujo Alternos

#### A1. El concursante no puede abrir el enlace

El sistema detecta que no se pudo abrir el enlace

El sistema muestra un mensaje “No se pudo abrir el documento. Por favor, inténtalo de nuevo”.

#### A2. El concursante no acepta los "Términos de avisos de privacidad" 

El sistema detecta que la casilla se encuentra vacía 

El sistema muestra el mensaje "Debe aceptar los términos de aviso de privacidad"

El sistema no permite avanzar hasta que se marque la casilla

# Trazabilidad
RF-006: Es el requisito previo, ya que la casilla de aceptación se encuentra en este formulario

RF-014: Funciona como requisito legal para validar la participación y generar el folio.

# Justificación y métrica

#### Punto de campo:
 El usuario debe conocer los Avisos de Privacidad de la campaña en que se encuentra participando para conocer cómo se tratarán sus datos personales.
#### Métrica: 
Los nuevos concursantes pueden acceder al documento de “avisos de privacidad” antes de completar su registro.
