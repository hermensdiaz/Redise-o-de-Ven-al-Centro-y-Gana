## RF-006 | Ventana emergente  

El sistema permite capturar los datos personales del concursante (nombre, primer apellido, segundo apellido, teléfono, correo electrónico y domicilio). 

## Objetivo 

Permitir al concursante registrar sus datos personales de manera segura y estandarizada. 

## Alcance 

El despliegue y validación del formulario de registro exclusivamente para usuarios nuevos (nombre, primer apellido, segundo apellido, teléfono, correo electrónico y domicilio). 

## Actores 

El Concursante (Cliente que participa en la dinámica). 

## Precondiciones 

El concursante debió haber entrado a la página de inicio y comenzar la fase de registro como usuario nuevo 

## Postcondiciones 

El concursante queda registrado con sus datos personales y comienza la fase de "Datos de la compra" con la elección de la sucursal y subida del ticket. 

## Flujo Principal 

1. El concursante ingresa su nombre. 

2. El concursante ingresa su primer apellido. 

3. El concursante ingresa su segundo apellido. 

4. El concursante ingresa su correo. 

5. El concursante ingresa su número. 

6. El concursante ingresa su domicilio. 

## Flujos Alternos 

A1. El concursante no ingresa su nombre 

El sistema detecta que el campo del nombre se encuentra vacío 

El sistema muestra el mensaje "Campo obligatorio" en la sección "Nombre" 

A2. El concursante no ingresa su Primer apellido 

El sistema detecta que el campo del apellido se encuentra vacío 

El sistema muestra el mensaje "Campo obligatorio" en la sección "Primer apellido" 

A3. El concursante no ingresa su Segundo apellido 

El sistema detecta que el campo del apellido se encuentra vacío 

El sistema muestra el mensaje "Campo obligatorio" en la sección "Segundo apellido" 

A4. El concursante no ingresa su correo de forma "nombre@correo.com" 

El sistema detecta que el campo del correo se no se encuentra en el formato establecido 

El sistema muestra el mensaje "Campo obligatorio" en la sección "Correo electrónico" 

A5. El concursante no ingresa su Número o lo captura mal. 

El sistema detecta que el campo del número se encuentra vacío o ingresa un carácter no numérico. 

El sistema muestra el mensaje "Campo obligatorio" en la sección "Número telefónico" 

A6. El concursante no ingresa su Domicilio. 

El sistema detecta que el campo del número se encuentra vacío o ingresa un carácter no numérico. 

El sistema muestra el mensaje "Campo obligatorio" en la sección "Domicilio”

## Justificación y Métricas de Campo 

Punto de campo: El concursante ingresa sus datos para que posteriormente si gana un premio por la trivia, entonces pueda ser contactado. 

Métrica: 4 de cada 5 personas de entre 40 años a 60 años y 9 de cada 10 personas de entre 20 a 30 años puedan registrar sus datos correctamente.
