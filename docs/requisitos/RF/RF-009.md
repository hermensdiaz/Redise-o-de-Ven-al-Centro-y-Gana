# RF-009
El sistema permite seleccionar la sucursal donde se realizó la compra. 

### Objetivo 
Registrar y asociar la compra realizada por el concursante mediante la captura de la sucursal para habilitar su acceso a la trivia. 
### Alcance 
Etapa de registro y carga del ticket de compra.

### Actores 
El concursante (cliente que participa en la dinámica). 

### Precondiciones 
El concursante ha registrado su número telefónico y datos personales correctamente. 

### Postcondiciones 
La participación queda ligada a la sucursal seleccionada y se habilita el acceso a la trivia. 

### Flujo principal
1.	El concursante selecciona la casilla “Seleccionar sucursal de compra”
2.	El sistema arroja el listado de sucursales participantes en la campaña
3.	El concursante selecciona la sucursal en donde se encuentra realizando la compra

### Flujos Alternos 
A1. El concursante no selecciona la sucursal: 
El sistema detecta que no ha sido seleccionada la sucursal. 
El sistema muestra el mensaje "Campo obligatorio".
