# RF-013 | Trivia 

El sistema muestra 3 preguntas de opción múltiple seleccionadas aleatoriamente que el concursante debe contestar todas correctamente para validar su participación. 

### Objetivo 

Participar en la dinámica de la trivia para poder participar para ganar un premio. 

### Alcance 

Comprende la selección aleatoria de 3 preguntas de opción múltiple (distribuidas en 3 pantallas consecutivas), la presentación de cada pregunta, la captura individual de cada respuesta que el concursante registra, la evaluación automática del resultado final y la redirección que el sistema ejecuta hacia el flujo de confirmación de participación exitosa o el sistema deriva de notificación de intento fallido. 

### Actores 

El concursante (cliente que participa en la dinámica). 

### Precondiciones 

El concursante debió haber registrado exitosamente la sucursal participante y la foto de un ticket de compra válido (RF-006). 

### Postcondiciones 

Las 3 preguntas seleccionadas aleatoriamente son respondidas y evaluadas por el sistema. 

Si obtiene 3/3 aciertos: El sistema deriva al flujo de confirmación de participación exitosa (RF-008). 

Si obtiene menos de 3 aciertos: El sistema deriva al flujo de notificación de intento fallido (RF-015 Si el concursante tiene un intento fallido. 

### Flujo Principal 

1. El sistema selecciona aleatoriamente 3 preguntas de opción múltiple del banco de datos. 

2. El concursante visualiza y responde la primera pregunta. 

3. El concursante visualiza y responde la segunda pregunta. 

4. El concursante visualiza y responde la tercera pregunta. 

5. El concursante presiona "Terminar trivia". 

6. El sistema evalúa las 3 respuestas y confirma que las 3 son correctas (100% de aciertos). 

7. El sistema redirige al flujo de notificación de éxito (RF-008). 

### Flujos Alternos  

A1. Una o más respuestas incorrectas: 

El sistema evalúa las respuestas y detecta al menos un fallo (si son menos de 3 respuestas correctas). 

El sistema redirige al flujo de notificación de intento fallido (RF-009). 

### Trazabilidad 

RF-009 Funciona como requisito previo obligatorio para acceder a la etapa de la trivia 

RF-010 Funciona como requisito previo obligatorio para acceder a la etapa de la trivia 

RF-011 Funciona como requisito previo obligatorio para acceder a la etapa de la trivia 

RF-012 Funciona como pantalla intermedia entre la subida del ticket y la trivia. 

RF-014: RF-013 funciona como requisito para mostrar la pantalla de trivia completada correctamente. 

RF-015: RF-013 funciona como requisito para mostrar la pantalla de trivia fallida. 

### Justificación y métrica  

La dinámica de Ven al Centro y Gana de CANACO SERVYTUR requiere la trivia para participar y poder ganar un premio. 

Métrica: La página debe mostrar las 3 preguntas, registrando cuánto es la tasa de éxito de las personas que registran sus tickets.
