# RF-002 | Pantalla de inicio 

El sistema permite redirigir al concursante a la lista de sucursales participantes en la campaña (páginas externas al sistema). 

### Objetivo 

Que el usuario pueda conocer que sucursales participan en la campaña. 

### Alcance 

La integración de un enlace que redireccione al usuario desde la aplicación hacia la lista de sucursales participantes mediante la apertura de una pestaña externa. 

### Actores 

El Concursante (Cliente que participa en la dinámica). 

### Precondiciones 

El concursante debió haber ingresado a la página de inicio desde el URL o el escaneo del QR de la campaña. 

### Postcondiciones 

El usuario ingresa al documento del listado de todas las sucursales participantes. 

### Flujo Principal 

El usuario ingresa a la página de inicio. 

El usuario ingresa al enlace del listado de sucursales participantes. 

El usuario es redireccionado al documento de sucursales participantes. 

### Flujos Alternos  

A1. URL Externa No Disponible: 

El sistema detecta que el enlace externo no responde o devuelve error. 

El sistema muestra un mensaje emergente: "Error 404". 

El sistema regresa al usuario a la pantalla de inicio. 

### Trazabilidad 

RF-001 Pantalla de inicio 

RF-003 Bases Oficiales. 

### Justificación y Métrica 

Justificación: Permitir que el concursante consulte de manera rápida las sucursales afiliadas a la campaña e ingresar su sucursal. 

Métrica: La página redirige al concursante a la lista de sucursales participantes.
