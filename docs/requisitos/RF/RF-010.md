# RF-010
El sistema permite ingresar el monto mínimo mostrado en el ticket de compra (mínimo $200).

### Objetivo 
Registrar y asociar la compra realizada por el concursante mediante la captura del monto monetario gastado para habilitar su acceso a la trivia. 

### Alcance 
Módulo de Registro de Participación del Sistema Web/Móvil. 

### Actores: 
El concursante (cliente que participa en la dinámica). 

### Precondiciones: 
El concursante ha registrado su número telefónico y datos 
personales correctamente. 

### Postcondiciones: 
El ticket queda registrado en estado y se habilita el acceso a la trivia. 

### Flujo Principal:
1.	El concursante ha realizado el proceso establecido en RF-009

2.	El concursante ingresa su monto de compra
### Flujos Alternos: 
#### A1. El concursante ingresa un monto menor al permitido. 
El sistema detecta que el monto es inferior a $200. 

El sistema muestra mensaje: "El monto mínimo para participar es de $200". 

El concursante ajusta el monto o cancela. 
#### A2. El concursante no ingresa ningún monto de compra.
El sistema detecta que la casilla se encuentra vacía

El sistema muestra mensaje: "Campo obligatorio".

El concursante ingresa el monto.

### Justificación y métrica
Justificación: El sistema necesita validar que el concursante cumpla con el monto de compra mínimo.

Métrica: El sistema captura el monto promedio de compra de las personas que realizan el registro de su ticket.
