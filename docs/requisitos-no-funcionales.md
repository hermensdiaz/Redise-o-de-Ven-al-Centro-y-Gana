# Requisitos no funcionales

Cada requisito tiene un ID para poder referenciarlo en Issues, commits y pruebas.


### Interoperabilidad 

* **RNF-001**: La dirección web de la app debe aparecer entre las primeras búsquedas en el navegador. 

### Usabilidad 

* **RNF-002**: En el RF-005 se debe especificar los datos a ingresar con un ejemplo (nombre, apellidos, teléfono, correo electrónico y domicilio). 

* **RNF-003**: El botón de regresar al apartado anterior y el de regresar al inicio no debe obstaculizar con el registro de datos. 

* **RNF-004**: En el RF-006 al momento de seleccionar la sucursal, debe aparecer un ícono de carga que le indique al usuario que está cargando las sucursales, por dos segundos. 

* **RNF-005**: El sistema debe tener interfaces gráficas atractivas. 

* **RNF-006**: El sistema formula las preguntas de la trivia empleando una redacción directa y un nivel de dificultad sencillo para asegurar su comprensión por todo el público. 

### Portabilidad 

* **RNF-007**: El sistema debe de ser capaz de ejecutarse tanto en celulares como en tabletas. 

### Eficiencia 

* **RNF-008**: El sistema gestiona la subida asíncrona de las fotografías de los tickets con alta estabilidad, evitando fallos que expulsen inesperadamente a los usuarios de la plataforma durante el escaneo.
