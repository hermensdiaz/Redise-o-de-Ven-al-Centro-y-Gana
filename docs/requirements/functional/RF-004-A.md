# RF-004-A | Ingreso con número telefónico
El sistema permite ingresar un número de teléfono de 10 dígitos y lo consulta en la base de datos en tiempo real para determinar si el concursante es usuario de primer ingreso o usuario ya registrado.

### Objetivo 
Identificar el estado del concursante en el sistema a partir de su número telefónico. 

### Alcance  
Pantalla "Ingresa tu número de celular": campo "Número de celular" con prefijo "+52", texto de ejemplo y contador de dígitos; validación de formato (10 dígitos numéricos) al presionar "Siguiente"; consulta inmediata en la base de datos. La casilla del aviso de privacidad **no** aparece en esta pantalla (ver RF-008).

### Actores 
El Concursante (Usuario que participa en la dinámica). 

### Precondiciones 
El concursante presionó el botón "Comenzar" en la pantalla de inicio, "Corregir mi número" en la ventana emergente (RF-005), o "Registrar otra compra" en una pantalla de resultado (RF-020).

### Postcondiciones 
- Si el número ya existe: el sistema muestra la pantalla de bienvenida para usuarios registrados y lo dirige a la fase de datos de la compra (RF-005, A1).
- Si el número NO existe: el sistema despliega la ventana emergente informativa para nuevos usuarios (RF-005).

### Flujo Principal 
1. El sistema presenta la pantalla "Ingresa tu número de celular" con el indicador "Paso 1 de 4" (RNF-007), el campo "Número de celular" con el prefijo "+52", el ejemplo "Ej.: 999 413 6967" y un contador de dígitos.
2. El concursante digita su número telefónico; el contador se actualiza (por ejemplo, "10/10").
3. El concursante presiona el botón "Siguiente".
4. El sistema valida el formato (RF-021) y consulta la base de datos.
5. El sistema determina que el número no se encuentra registrado y despliega la ventana emergente para nuevos usuarios (RF-005).

### Flujos Alternos 
A1. El concursante no ingresa ningún dato. 
1. El sistema detecta que la casilla se encuentra vacía. 
2. El sistema muestra el mensaje "Campo obligatorio". 

A2. El concursante ingresa un número inferior a 10 dígitos. 
1. El sistema detecta que el número ingresado no es válido.
2. El sistema muestra el mensaje "El número es muy corto. Te faltan N dígitos.", donde N es el número de dígitos faltantes. 

A3. El concursante ingresa un número superior a 10 dígitos. 
1. El campo no permite escribir más de 10 dígitos. Si el número llega pegado con más dígitos, el sistema lo detecta como no válido.
2. El sistema muestra el mensaje "El número es muy largo".

A4. El concursante ingresa caracteres no numéricos.
1. El campo abre el teclado numérico (RNF-009). Si aun así llegan caracteres no numéricos, el sistema lo detecta.
2. El sistema muestra el mensaje "Solo se permiten caracteres numéricos".

A5. El número ya está registrado.
1. El sistema muestra la pantalla de bienvenida para usuarios registrados (RF-005, A1).

A6. El concursante es nuevo y prefiere registrarse directamente.
1. El concursante presiona "Registrarme por primera vez" (RF-004-B).

A7. El concursante presiona "Regresar".
1. El sistema muestra la pantalla de inicio (RF-001).

### Trazabilidad 
- RF-001: Pantalla previa. 
- RF-004-B: Camino directo para usuarios nuevos.
- RF-005: Ventana emergente para números no registrados y bienvenida para usuarios registrados.
- RF-006, RF-008: Siguientes pasos si el concursante no se encuentra registrado. 
- RF-009, RF-010, RF-011: Siguientes pasos si el concursante ya se encuentra registrado. 
- RF-016: Confirmación al presionar el ícono de inicio.
- RF-020: Llegada desde "Registrar otra compra".
- RF-021: Validación al presionar "Siguiente".
- RNF-007, RNF-009, RNF-010: Indicador de progreso, teclado numérico y formato de errores.

### Justificación y métrica
**Justificación:** Permite conocer si el número telefónico ya ha sido registrado. 

**Métrica:** El 98 % de los concursantes que inician la captura del número telefónico debe completar la verificación con éxito.
