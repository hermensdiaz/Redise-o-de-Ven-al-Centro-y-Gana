# RF-008 | Aviso de privacidad
El sistema debe permitir al usuario consultar y aceptar el aviso de privacidad mediante un enlace que abre el documento en una nueva pestaña.

### Objetivo
Proporcionar transparencia legal al concursante, para que conozca cómo se tratarán sus datos personales antes de aceptarlo.

### Alcance 
Cubre la casilla "He leído y acepto el aviso de privacidad" y su enlace, presentes **únicamente** en el formulario de registro de datos personales (RF-006). Incluye un ícono junto al enlace que indica que el documento se abre en otra pestaña. La casilla no aparece en la pantalla de ingreso con teléfono (RF-004-A).

### Actores 
El Concursante (Usuario que participa en la dinámica).

### Precondiciones
El concursante ingresó a la página web de la campaña mediante el enlace o el QR, comenzó su registro como usuario nuevo y se encuentra en el formulario de registro de datos personales.

### Postcondiciones
El documento del aviso de privacidad queda visible en una nueva pestaña y el concursante puede regresar a la página web para continuar con su registro, con sus datos intactos.

### Flujo Principal
1. El concursante presiona el enlace "aviso de privacidad" (con el ícono de pestaña externa).
2. El sistema abre una nueva pestaña con el documento del aviso de privacidad.
3. El concursante lee el documento.
4. El concursante cierra la pestaña y regresa a la fase de registro como usuario nuevo.
5. El concursante marca la casilla "He leído y acepto el aviso de privacidad".

### Flujos Alternos
A1. El concursante no puede abrir el enlace.
1. El sistema detecta que no se pudo abrir el enlace.
2. El sistema muestra el mensaje "No se pudo abrir el documento. Por favor, inténtalo de nuevo".

A2. El concursante no acepta el aviso de privacidad.
1. Al presionar "Siguiente", el sistema detecta que la casilla está vacía.
2. El sistema marca la casilla con borde rojo y muestra el mensaje "Debes aceptar el aviso de privacidad" (RNF-010).
3. El sistema incluye este error en el resumen de errores (RF-021) y no permite avanzar hasta que se marque la casilla.

### Trazabilidad
- RF-006: Requisito previo, ya que la casilla de aceptación se encuentra en ese formulario.
- RF-014: Requisito legal para validar la participación y generar el folio.
- RF-021: Validación al presionar "Siguiente".
- RNF-008: Área táctil mínima de 44 × 44 px para la casilla.
- RNF-011: Protección de los datos personales en pantalla.

### Justificación y métrica
**Punto de campo:** El usuario debe conocer el aviso de privacidad de la campaña en la que participa para saber cómo se tratarán sus datos personales.

**Métrica:** El 100 % de los nuevos concursantes debe poder acceder al aviso de privacidad antes de completar su registro.
