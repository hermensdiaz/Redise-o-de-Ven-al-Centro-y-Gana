# RF-021 | Validación al avanzar y resumen de errores

El sistema valida los datos de un formulario cuando el concursante presiona "Siguiente". Si hay errores, muestra en la parte superior un resumen con el número de datos por corregir ("Revisa N datos marcados en rojo para continuar.") y marca cada campo con error con su mensaje correspondiente.

### Objetivo
Que el concursante sepa cuántos y cuáles datos debe corregir, en lugar de enfrentarse a un botón deshabilitado sin explicación.

### Alcance
Aplica a los formularios de ingreso con teléfono (RF-004-A), registro de datos personales (RF-006, RF-008) y datos de la compra (RF-009, RF-010, RF-011). El botón "Siguiente" permanece activo y la validación ocurre al presionarlo. Los mensajes de cada campo son los definidos en cada RF.

### Actores
El Concursante (Usuario que participa en la dinámica).

### Precondiciones
El concursante se encuentra en uno de los formularios mencionados.

### Postcondiciones
- Sin errores: el sistema avanza a la siguiente pantalla.
- Con errores: el concursante permanece en la pantalla, con los datos que capturó correctamente intactos.

### Flujo Principal
1. El concursante captura los datos y presiona "Siguiente".
2. El sistema valida todos los campos.
3. El sistema no encuentra errores y avanza a la siguiente pantalla.

### Flujos Alternos
A1. Hay uno o más errores.
1. El sistema muestra en la parte superior el recuadro "Revisa N datos marcados en rojo para continuar.", donde N es el número de errores.
2. El sistema marca cada campo con error con borde rojo y debajo muestra un ícono de alerta con el mensaje correspondiente.
3. El concursante corrige los datos y presiona "Siguiente" de nuevo.

### Trazabilidad
- RF-004-A, RF-006, RF-008, RF-009, RF-010, RF-011: mensajes de error de cada campo.
- RNF-005: borde rojo (#DC3545) y texto explicativo en los campos con error.
- RNF-010: formato de los mensajes de error.

### Justificación y métrica
**Justificación:** Un botón deshabilitado no explica qué falta, y la prueba de campo mostró usuarios que no sabían qué hacer en el formulario (RF-006). Señalar el número y la ubicación de los errores orienta la corrección.
**Métrica (propuesta):** El 90 % de los concursantes que ven el resumen de errores corrige sus datos y avanza en el siguiente intento.
