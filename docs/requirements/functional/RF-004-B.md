# RF-004 | Registro de participación 
El sistema permite mostrar un botón o enlace que redirige al usuario a la fase de registro del ticket en el caso que no se haya registrado anteriormente.

### Objetivo 
Redirigir al concursante a la fase de registro para registrarse como usuario nuevo. 

### Alcance  
<!-- Pendiente -->
Captura del número, validación de formato (10 dígitos numéricos) y consulta inmediata en la base de datos. 

### Actores 
El Concursante (Usuario que participa en la dinámica). 

### Precondiciones 
El concursante presionó el botón comenzar en la pantalla de inicio.  

### Postcondiciones 
Redirigir al usuario a la fase de registro.

### Flujo Principal 
1. El sistema presenta el campo de captura para ingresar el número telefónico, el cual debe contener 10 caracteres numéricos.
2. El concursante presiona el botón o enlace "Presione aquí para registrarse"
3. El sistema redirige al usuario a la fase de registro.

### Flujo alterno 
A1. El concursante no presiona el botón o enlace. 
El usuario continúa el proceso ya establecido en el RF-004-A

### Justificación 
**Justificación:** Permitir al usuario poder registrarse como usuario nuevo.

**Métrica:** Permitir que todos los usuarios sean redirigidos a la fase de registro de datos.
