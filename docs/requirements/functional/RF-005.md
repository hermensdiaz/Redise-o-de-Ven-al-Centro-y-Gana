# RF-005 | Ventana emergente de número no registrado
Con base en lo obtenido en RF-004-A, el sistema muestra una ventana emergente con el mensaje "Este número aún no está registrado" y lleva al concursante a la fase de registro de datos. Si el número ya está registrado, muestra una pantalla de bienvenida.

### Objetivo 
Notificar al concursante que su número no está registrado, mediante una ventana emergente, y llevarlo al formulario de RF-006; o darle la bienvenida si ya está registrado.

### Alcance  
- Ventana emergente "Este número aún no está registrado" con los botones "Registrar mis datos" y "Corregir mi número".
- Pantalla "¡Hola de nuevo, [nombre]!" para usuarios ya registrados, con el número enmascarado (RNF-011) y el botón "Continuar".

### Actores
El Concursante (Usuario que participa en la dinámica). 

### Precondición 
El concursante ingresó su número telefónico y presionó "Siguiente" en RF-004-A.

### Postcondición 
El concursante pasa al formulario de RF-006 conservando su número telefónico, que aparece prellenado, para iniciar el registro de datos.

### Flujo principal 
1. El sistema muestra una ventana emergente con el título "Este número aún no está registrado" y el mensaje "No encontramos participaciones con el [número]. Vamos a registrar tus datos; solo toma un minuto." 
2. El concursante presiona "Registrar mis datos". 
3. El sistema muestra el formulario de registro de datos personales (RF-006) con el número prellenado. 

### Flujos Alternos  
A1. Usuario ya registrado: 
1. El sistema identifica que el número telefónico ya existe en la base de datos. 
2. El sistema muestra la pantalla "¡Hola de nuevo, [nombre]!" con el texto "Celular: [número enmascarado]" (por ejemplo, "999 ••• 9207") y el mensaje "Ya tenemos tus datos. Solo registra tu nueva compra." 
3. El concursante presiona "Continuar".
4. El sistema omite la captura de datos personales (RF-006) y lo lleva a los datos de la compra (RF-009).

A2. Formato de teléfono inválido: 
1. El concursante ingresa un número con menos o más de 10 dígitos o con caracteres no numéricos. 
2. El sistema muestra el mensaje de error correspondiente de RF-004-A (A1 a A4) y no muestra la ventana emergente. 
3. El sistema permanece en la misma pantalla hasta que se corrige el dato. 

A3. El concursante se equivocó al escribir su número:
1. En la ventana emergente, el concursante presiona "Corregir mi número".
2. El sistema cierra la ventana emergente y regresa a la pantalla de ingreso con teléfono (RF-004-A), con el número capturado para editarlo.

### Trazabilidad 
- RF-001: El flujo de verificación telefónica se desencadena cuando el concursante presiona "Comenzar" en la pantalla de inicio. 
- RF-004-A: Pantalla previa, donde se captura y valida el número.
- RF-006, RF-008: Si el número no existe, el sistema habilita la captura de datos personales y la aceptación del aviso de privacidad. 
- RF-009: Si el número ya está registrado, el sistema omite el registro de datos y lleva al concursante directamente a los datos de la compra. 
- RF-014: El número validado en este paso es al que se envía el SMS con el folio de participación. 
- RF-015, RF-020: El número es la clave de identificación del concursante para volver a participar con un nuevo ticket. 
- RNF-011: Enmascaramiento del número en la pantalla de bienvenida.

### Justificación y métrica 
**Justificación:** En el caso de los usuarios ya registrados, agilizar el inicio de sesión para minimizar el tiempo de registro del ticket; de esta forma se maximiza el tiempo que tienen los clientes para subir más tickets. 

**Métrica:** Reducir el tiempo de inicio de flujo de 1.5 minutos a menos de 10 segundos para usuarios recurrentes.
