# RF-006 | Registro de datos personales
El sistema permite capturar los datos personales del concursante (nombre, primer apellido, segundo apellido, teléfono, correo electrónico y domicilio). 

### Objetivo 
Permitir al concursante registrar sus datos personales de manera segura y estandarizada. 

### Alcance 
Despliegue y validación del formulario "Ingresa tus datos", exclusivo para usuarios nuevos: nombre(s), primer apellido, segundo apellido, número de celular (prellenado), correo electrónico y domicilio, más la casilla del aviso de privacidad (RF-008). Incluye el aviso "Todos los campos son obligatorios." y la validación al presionar "Siguiente" (RF-021).

### Actores 
El Concursante (Usuario que participa en la dinámica). 

### Precondiciones 
El concursante comenzó la fase de registro como usuario nuevo: presionó "Registrar mis datos" (RF-005) o "Registrarme por primera vez" (RF-004-B).

### Postcondiciones 
El concursante queda registrado con sus datos personales y comienza la fase "Datos de la compra", con la elección de la sucursal y la foto del ticket. 

### Flujo Principal 
1. El sistema muestra el formulario "Ingresa tus datos" con el subtítulo "Todos los campos son obligatorios.", el indicador "Paso 1 de 4" y los ejemplos dentro de cada campo (RF-007).
2. El concursante ingresa su nombre. 
3. El concursante ingresa su primer apellido. 
4. El concursante ingresa su segundo apellido. 
5. El concursante verifica su número de celular, que viene prellenado desde RF-004-A con el texto de ayuda "Lo tomamos del paso anterior. Aquí te enviaremos tu folio."; si llegó desde RF-004-B, lo ingresa. 
6. El concursante ingresa su correo electrónico. 
7. El concursante ingresa su domicilio. 
8. El concursante acepta el aviso de privacidad (RF-008).
9. El concursante presiona "Siguiente".
10. El sistema valida todos los campos (RF-021) y muestra la pantalla de datos de la compra (RF-009).

### Flujos Alternos 
A1. El concursante no ingresa su nombre. 
1. El sistema detecta que el campo del nombre se encuentra vacío. 
2. El sistema muestra el mensaje "Campo obligatorio" en el campo "Nombre(s)". 

A2. El concursante no ingresa su primer apellido. 
1. El sistema detecta que el campo se encuentra vacío. 
2. El sistema muestra el mensaje "Campo obligatorio" en el campo "Primer apellido". 

A3. El concursante no ingresa su segundo apellido. 
1. El sistema detecta que el campo se encuentra vacío. 
2. El sistema muestra el mensaje "Campo obligatorio" en el campo "Segundo apellido". 

A4. El concursante no ingresa su correo con la forma "nombre@correo.com". 
1. El sistema detecta que el correo no tiene el formato establecido. 
2. El sistema muestra el mensaje "Falta la terminación del correo, por ejemplo: nombre@correo.com" en el campo "Correo electrónico". Si el campo está vacío, muestra "Campo obligatorio". 

A5. El concursante no ingresa su número o lo captura mal. 
1. El sistema detecta que el campo está vacío o tiene un carácter no numérico. 
2. El sistema muestra el mensaje correspondiente de RF-004-A (A1 a A4) en el campo "Número de celular". 

A6. El concursante no ingresa su domicilio. 
1. El sistema detecta que el campo del domicilio se encuentra vacío. 
2. El sistema muestra el mensaje "Campo obligatorio" en el campo "Domicilio". 

A7. Hay uno o más errores al presionar "Siguiente".
1. El sistema muestra arriba el resumen "Revisa N datos marcados en rojo para continuar." (RF-021) y conserva los datos correctos.

A8. El concursante ya había participado antes.
1. El concursante presiona "¿Ya participaste antes? Ingresa con tu número" y el sistema lo regresa a RF-004-A (RF-004-B, A2).

A9. El concursante presiona el ícono de inicio.
1. El sistema pide confirmación antes de salir (RF-016).

### Trazabilidad 
- RF-004-A, RF-004-B, RF-005: Requisitos previos indispensables para acceder a la captura de datos. 
- RF-007: Ejemplos dentro de los campos.
- RF-008: Aviso de privacidad dentro de este formulario.
- RF-009, RF-010, RF-011: RF-006 actúa como requisito previo para acceder. 
- RF-014: Los datos de RF-006 se usan para enviar el folio una vez terminada la trivia.
- RF-016, RF-021: Salida con confirmación y validación con resumen de errores.
- RNF-002, RNF-008, RNF-009, RNF-010: Ejemplos, tamaños, teclados y formato de errores.

### Justificación y Métricas de Campo 
**Justificación:** El concursante ingresa sus datos para que, si gana un premio por la trivia, pueda ser contactado. 

**Métrica:** 4 de cada 5 personas de entre 40 y 60 años, y 9 de cada 10 personas de entre 20 y 30 años, pueden registrar sus datos correctamente.
