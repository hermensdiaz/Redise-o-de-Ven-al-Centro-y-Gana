# RF-009 | Selección de sucursal
El sistema permite seleccionar la sucursal donde se realizó la compra. 

### Objetivo 
Registrar y asociar la compra realizada por el concursante mediante la captura de la sucursal, para habilitar su acceso a la trivia. 

### Alcance 
Campo "Sucursal donde compraste" de la pantalla "Registra tu compra" (Paso 2 de 4). La selección se hace en el panel de búsqueda definido en RF-017.

### Actores 
El Concursante (Usuario que participa en la dinámica). 

### Precondiciones 
El concursante registró su número telefónico y sus datos personales correctamente (RF-006), o fue identificado como usuario ya registrado y presionó "Continuar" (RF-005, A1).

### Postcondiciones 
La participación queda ligada a la sucursal seleccionada, y el campo muestra su nombre y calle. 

### Flujo principal
1. El sistema muestra la pantalla "Registra tu compra" con el indicador "Paso 2 de 4" y el campo "Sucursal donde compraste" con el texto de ejemplo "Elige una sucursal".
2. El concursante toca el campo.
3. El sistema despliega el panel "Elige la sucursal" con el buscador y el listado de sucursales participantes (RF-017).
4. El concursante busca y selecciona la sucursal donde realizó la compra.
5. El sistema cierra el panel y muestra la sucursal en el campo (por ejemplo, "Soriana Centro · Calle 60").

### Flujos Alternos 
A1. El concursante no selecciona la sucursal: 
1. Al presionar "Siguiente", el sistema detecta que no ha sido seleccionada la sucursal. 
2. El sistema muestra el mensaje "Campo obligatorio" e incluye el error en el resumen de errores (RF-021). 

A2. El concursante no encuentra su sucursal:
1. El sistema ofrece el enlace a la lista de comercios participantes (RF-017, A2; RF-002).

A3. El concursante presiona "Regresar":
1. El sistema muestra la pantalla anterior conservando los datos capturados.

### Trazabilidad
- RF-005, RF-006, RF-007, RF-008: Condiciones requeridas antes de acceder a la fase de registro del ticket. 
- RF-017: Búsqueda de sucursal.
- RF-012: RF-009 actúa como condición obligatoria para acceder.
- RF-016, RF-021: Salida con confirmación y validación con resumen de errores.
- RNF-004: Tiempo de carga del catálogo de sucursales.

### Justificación y métrica
**Justificación:** El sistema requiere conocer en qué sucursal participante se realizó la compra.

**Métrica:** El 95 % de los concursantes debe lograr seleccionar la sucursal de compra en el primer intento, sin mostrar el mensaje "Campo obligatorio".
