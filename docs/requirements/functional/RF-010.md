# RF-010 | Monto de la compra
El sistema permite ingresar el monto mostrado en el ticket de compra, que debe ser de al menos $200.

### Objetivo 
Registrar y asociar la compra realizada por el concursante mediante la captura del monto gastado, para habilitar su acceso a la trivia. 

### Alcance 
Campo "Total de tu ticket" de la pantalla "Registra tu compra", con el prefijo "$", el sufijo "MXN", el ejemplo "Ej.: 350.00" y el texto de ayuda permanente "La compra mínima es de $200.". El campo abre el teclado numérico con punto decimal (RNF-009).

### Actores
El Concursante (Usuario que participa en la dinámica).  

### Precondiciones
El concursante registró su número telefónico y sus datos personales correctamente, o fue identificado como usuario ya registrado (RF-005, A1). 

### Postcondiciones
El monto queda registrado en la participación, y se habilita el acceso a la trivia cuando también están la sucursal y la foto. 

### Flujo Principal
1. El concursante realizó el proceso establecido en RF-009.
2. El sistema muestra el campo "Total de tu ticket" con el texto de ayuda "La compra mínima es de $200.".
3. El concursante ingresa el monto de su compra.

### Flujos Alternos
A1. El concursante ingresa un monto menor al permitido.
1. Al presionar "Siguiente", el sistema detecta que el monto es inferior a $200. 
2. El sistema muestra el mensaje "El monto mínimo para participar es de $200" y lo incluye en el resumen de errores (RF-021). 
3. El concursante ajusta el monto o abandona el registro. 

A2. El concursante no ingresa ningún monto de compra.
1. El sistema detecta que el campo se encuentra vacío.
2. El sistema muestra el mensaje "Campo obligatorio".
3. El concursante ingresa el monto.

### Trazabilidad
- RF-005, RF-006, RF-007, RF-008: Condiciones requeridas antes de acceder a la fase de registro del ticket. 
- RF-009: Paso previo dentro de la misma pantalla.
- RF-012: RF-010 actúa como condición obligatoria para desbloquear la trivia. 
- RF-021: Validación con resumen de errores.
- RNF-009, RNF-010: Teclado numérico y formato del mensaje de error.

### Justificación y métrica
**Justificación:** El sistema necesita validar que el concursante cumpla con el monto de compra mínimo.

**Métrica:** El sistema captura el monto promedio de compra de las personas que realizan el registro de su ticket.
