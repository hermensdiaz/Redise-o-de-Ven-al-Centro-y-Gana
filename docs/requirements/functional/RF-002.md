# RF-002 | Lista de comercios participantes
El sistema permite redirigir al concursante a la lista de sucursales participantes en la campaña (páginas externas al sistema). 

### Objetivo 
Que el usuario pueda conocer qué sucursales participan en la campaña. 

### Alcance 
Enlaces que redireccionan al usuario desde la aplicación hacia la lista de sucursales participantes, abriendo una pestaña externa. Hay dos puntos de acceso:
- El enlace "Ver comercios" en la pantalla de inicio (RF-001).
- El enlace "lista de comercios participantes" en el panel de búsqueda de sucursal (RF-017).

### Actores 
El Concursante (Usuario que participa en la dinámica). 

### Precondiciones 
El concursante debió haber ingresado a la página de inicio desde la URL o el escaneo del QR de la campaña, o encontrarse en el panel de búsqueda de sucursal. 

### Postcondiciones 
El usuario ingresa al documento del listado de todas las sucursales participantes, en una pestaña nueva. La pestaña de la aplicación conserva su estado. 

### Flujo Principal 
1. El usuario ingresa a la página de inicio. 
2. El usuario presiona el enlace "Ver comercios". 
3. El sistema abre el documento de sucursales participantes en una pestaña nueva. 

### Flujos Alternos  
A1. URL externa no disponible: 
1. El sistema detecta que el enlace externo no responde o devuelve error. 
2. El sistema muestra un mensaje emergente: "Error 404". 
3. El sistema regresa al usuario a la pantalla de inicio. 

A2. Acceso desde la búsqueda de sucursal:
1. El concursante no encuentra su sucursal en el panel de búsqueda (RF-017).
2. El concursante presiona el enlace "lista de comercios participantes".
3. El sistema abre el documento en una pestaña nueva; el panel y los datos de la compra se conservan.

### Trazabilidad 
- RF-001: Pantalla de inicio.
- RF-003: Bases oficiales.
- RF-017: Búsqueda de sucursal (segundo punto de acceso).

### Justificación y Métrica 
**Justificación:** Permitir que el concursante consulte de manera rápida las sucursales afiliadas a la campaña e ingrese su sucursal. 

**Métrica:** La página redirige al concursante a la lista de sucursales participantes.
