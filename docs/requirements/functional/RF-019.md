# RF-019 | Navegación entre preguntas de la trivia

El sistema permite al concursante avanzar entre las preguntas de la trivia con el botón "Siguiente pregunta" y regresar a la pregunta anterior para cambiar su respuesta antes de presionar "Terminar trivia". Además, muestra el número de pregunta actual ("Pregunta X de 3") con indicadores de avance.

### Objetivo
Que el concursante sepa cuántas preguntas le faltan y pueda corregir una respuesta antes de que el sistema evalúe la trivia.

### Alcance
Cubre las tres pantallas de preguntas de la trivia: contador "Pregunta X de 3", indicadores de avance, botón "Siguiente pregunta" (preguntas 1 y 2), enlace "Pregunta anterior" (preguntas 2 y 3) y botón "Terminar trivia" (pregunta 3). No cubre la evaluación de respuestas, que pertenece a RF-013.

### Actores
El Concursante (Usuario que participa en la dinámica).

### Precondiciones
El concursante presionó "Entendido" en la pantalla de instrucciones (RF-012).

### Postcondiciones
Las respuestas elegidas se conservan al moverse entre preguntas; la evaluación ocurre solo al presionar "Terminar trivia".

### Flujo Principal
1. El sistema muestra la pregunta 1 con el contador "Pregunta 1 de 3".
2. El concursante elige una respuesta y presiona "Siguiente pregunta".
3. El sistema muestra la pregunta 2 y, después, la pregunta 3 con el mismo comportamiento.
4. En la pregunta 3, el concursante elige una respuesta y presiona "Terminar trivia".
5. El sistema evalúa las respuestas (RF-013).

### Flujos Alternos
A1. El concursante quiere cambiar una respuesta.
1. El concursante presiona "Pregunta anterior".
2. El sistema muestra la pregunta anterior con la respuesta que había elegido marcada.
3. El concursante cambia su respuesta y avanza de nuevo.

A2. El concursante no ha elegido una respuesta.
1. El sistema no permite avanzar hasta que se elija una opción.

### Trazabilidad
- RF-012: pantalla previa.
- RF-013: selección y evaluación de las preguntas.
- RF-014, RF-015: pantallas de resultado.
- RNF-006: presentación de las preguntas.

### Justificación y métrica
**Justificación:** Saber cuántas preguntas faltan reduce la incertidumbre del concursante. Poder corregir una respuesta antes de terminar evita reintentos por un toque equivocado, un problema observado en celulares pequeños (RNF-003).
**Métrica (propuesta):** Al menos el 95 % de los concursantes que inician la trivia presiona "Terminar trivia" sin abandonar (alineada con RF-013).
