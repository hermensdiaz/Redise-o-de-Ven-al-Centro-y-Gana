# RF-013 | Trivia 
El sistema muestra 3 preguntas de opción múltiple seleccionadas aleatoriamente, que el concursante debe contestar todas correctamente para validar su participación. 

### Objetivo 
Que el concursante participe en la dinámica de la trivia para tener la oportunidad de ganar un premio. 

### Alcance 
Comprende la selección aleatoria de 3 preguntas de opción múltiple (en 3 pantallas consecutivas), la presentación de cada pregunta como tarjetas de respuesta (RNF-006), la captura de cada respuesta, la evaluación automática del resultado final y la redirección a la pantalla de participación confirmada o a la de respuestas incorrectas. La navegación entre preguntas se define en RF-019. 

### Actores 
El Concursante (Usuario que participa en la dinámica). 

### Precondiciones 
El concursante registró exitosamente la sucursal participante, el monto y la foto de un ticket de compra válido (RF-009, RF-010, RF-011), y presionó "Entendido" (RF-012). 

### Postcondiciones 
Las 3 preguntas seleccionadas aleatoriamente son respondidas y evaluadas por el sistema. 

**Si obtiene 3/3 aciertos:** El sistema deriva al flujo de confirmación de participación exitosa (RF-014). 

**Si obtiene menos de 3 aciertos:** El sistema deriva al flujo de respuestas incorrectas (RF-015). 

### Flujo Principal 
1. El sistema selecciona aleatoriamente 3 preguntas de opción múltiple del banco de datos. 
2. El sistema muestra la primera pregunta con el contador "Pregunta 1 de 3" y sus opciones como tarjetas.
3. El concursante elige una respuesta y presiona "Siguiente pregunta". 
4. El concursante visualiza y responde la segunda pregunta, y presiona "Siguiente pregunta". 
5. El concursante visualiza y responde la tercera pregunta. 
6. El concursante presiona "Terminar trivia". 
7. El sistema evalúa las 3 respuestas y confirma que las 3 son correctas (100 % de aciertos). 
8. El sistema muestra la pantalla de participación confirmada (RF-014). 

### Flujos Alternos  
A1. Una o más respuestas incorrectas: 
1. El sistema evalúa las respuestas y detecta al menos un fallo (menos de 3 respuestas correctas). 
2. El sistema muestra la pantalla de respuestas incorrectas (RF-015). 

A2. El concursante quiere cambiar una respuesta antes de terminar:
1. El concursante presiona "Pregunta anterior" (RF-019, A1).

A3. El concursante no ha elegido una respuesta:
1. El sistema no permite avanzar hasta que elija una opción (RF-019, A2).

A4. El concursante presiona el ícono de inicio:
1. El sistema pide confirmación antes de salir (RF-016).

### Trazabilidad 
- RF-009, RF-010, RF-011: Requisitos previos obligatorios para acceder a la trivia. 
- RF-012: Pantalla intermedia entre la foto del ticket y la trivia. 
- RF-019: Navegación entre preguntas.
- RF-014: RF-013 es requisito para mostrar la pantalla de participación confirmada.
- RF-015: RF-013 es requisito para mostrar la pantalla de respuestas incorrectas. 
- RF-016: Confirmación al salir.
- RNF-006, RNF-008: Presentación de las preguntas y tamaño de las opciones.

### Justificación y métrica  
**Justificación:** La dinámica de Ven al Centro y Gana de CANACO SERVYTUR requiere la trivia para participar y poder ganar un premio. 

**Métrica:** Al menos el 95 % de los concursantes que inician la trivia debe responder las 3 preguntas y presionar "Terminar trivia" sin abandonar la pantalla.
