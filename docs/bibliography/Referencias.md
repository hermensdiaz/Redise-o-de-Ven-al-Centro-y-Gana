# Requisitos de software

## Competencias

* Identificar y comprender los requisitos funcionales y no funcionales de un sistema.
* Analizar las características y necesidades que debe cumplir un software.
* Diferenciar entre las funciones que realiza un sistema y las características de calidad que debe cumplir.

## Conceptos

| Concepto | Definición / Descripción |
| :--- | :--- |
| Requisito funcional | Un requisito funcional describe lo que debe hacer un sistema. Define las funciones, procesos específicos o comportamientos que el software debe realizar para satisfacer las necesidades de los usuarios o del negocio. Establece las entradas, procesos y salidas esperadas y especifica los servicios que debe proporcionar el sistema. |
| Requisito no funcional | Un requisito no funcional describe cómo debe funcionar un sistema y establece restricciones o atributos de calidad que debe cumplir, como rendimiento, seguridad, disponibilidad, usabilidad o características de la interfaz. No se enfoca en funciones específicas, sino en las condiciones y características que debe cumplir el sistema. |
