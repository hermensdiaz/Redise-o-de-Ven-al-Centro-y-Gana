# HU-007 | Ver ejemplos en los campos del formulario

**Requisito de origen:** RF-007  
**Requisitos relacionados:** RF-006, RNF-002  
**Prioridad:** Media  
**Estimación (sugerida):** 1 punto

## Historia

> **Como** concursante (especialmente mayor de 50 años),  
> **quiero** ver un ejemplo de qué escribir en cada campo del formulario,  
> **para** llenar mis datos sin dudas ni errores.

## Criterios de aceptación

**CA1. Ejemplos visibles**  
**Dado** que abro el formulario de datos personales,  
**cuando** veo los campos vacíos,  
**entonces** cada uno muestra dentro su ejemplo: "Ej.: Pánfilo", "Ej.: Palomo", "Ej.: Sánchez", "Ej.: 999 413 6967", "Ej.: nombre@correo.com" y "Ej.: Calle 13 #256, Centro, Mérida".

**CA2. El ejemplo no se confunde con un dato**  
**Dado** que un campo muestra su ejemplo,  
**cuando** empiezo a escribir en él,  
**entonces** el ejemplo desaparece y solo queda lo que yo escribí; la etiqueta del campo sigue visible arriba.

## Notas

- Es apoyo visual del formulario de HU-006.
