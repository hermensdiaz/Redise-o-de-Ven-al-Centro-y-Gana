# HU-004-A | Verificar mi número telefónico

**Requisito de origen:** RF-004-A  
**Prioridad:** Alta  
**Estimación (sugerida):** 5 puntos

## Historia

> **Como** concursante,  
> **quiero** ingresar mi número de teléfono de 10 dígitos,  
> **para** que el sistema sepa si soy nuevo o ya estoy registrado y me lleve al paso correcto.

## Criterios de aceptación

**CA1. Número no registrado**  
**Dado** que presioné "Comenzar" e ingreso un número válido de 10 dígitos que no existe en la base de datos,  
**cuando** presiono "Verificar",  
**entonces** el sistema muestra la ventana emergente para usuarios nuevos y me lleva al formulario de datos personales.

**CA2. Número ya registrado**  
**Dado** que ingreso un número válido que ya existe en la base de datos,  
**cuando** presiono "Verificar",  
**entonces** el sistema me indica que ya estoy registrado y me lleva a "Datos de la compra".

**CA3. Campo vacío**  
**Dado** que no escribo ningún número,  
**cuando** presiono "Verificar",  
**entonces** veo el mensaje "Campo obligatorio".

**CA4. Número corto**  
**Dado** que escribo menos de 10 dígitos,  
**cuando** presiono "Verificar",  
**entonces** veo el mensaje "El número es muy corto".

**CA5. Número largo**  
**Dado** que escribo más de 10 dígitos,  
**cuando** presiono "Verificar",  
**entonces** veo el mensaje "El número es muy largo".

**CA6. Caracteres no numéricos**  
**Dado** que escribo letras o símbolos,  
**cuando** presiono "Verificar",  
**entonces** veo el mensaje "Solo se permiten caracteres numéricos".

## Notas

- La consulta a la base de datos es en tiempo real.
- Métrica: el 98 % de quienes inician la captura completa la verificación con éxito.
