# HU-002 | Consultar comercios participantes

**Requisito de origen:** RF-002  
**Requisitos relacionados:** RF-001, RF-017  
**Prioridad:** Media  
**Estimación (sugerida):** 1 punto

## Historia

> **Como** concursante,  
> **quiero** abrir la lista de comercios participantes desde la pantalla de inicio o mientras elijo mi sucursal,  
> **para** saber en qué tiendas puedo comprar para participar.

## Criterios de aceptación

**CA1. Abrir la lista desde el inicio**  
**Dado** que estoy en la pantalla de inicio,  
**cuando** presiono "Ver comercios",  
**entonces** se abre en una pestaña externa el documento con la lista de sucursales.

**CA2. Abrir la lista desde la búsqueda de sucursal**  
**Dado** que estoy en el panel "Elige la sucursal" y no encuentro la mía,  
**cuando** presiono el enlace "lista de comercios participantes",  
**entonces** se abre en una pestaña externa el documento, y mis datos de la compra se conservan.

**CA3. Enlace no disponible**  
**Dado** que el enlace externo no responde o devuelve error,  
**cuando** presiono el enlace,  
**entonces** el sistema muestra el mensaje emergente "Error 404" y me regresa a la pantalla de inicio.

## Notas

- Métrica: la página redirige al concursante a la lista de sucursales participantes.
