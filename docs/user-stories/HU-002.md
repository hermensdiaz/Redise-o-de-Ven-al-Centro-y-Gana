# HU-002 | Consultar sucursales participantes

**Requisito de origen:** RF-002  
**Prioridad:** Media  
**Estimación (sugerida):** 1 puntos

## Historia

> **Como** concursante,  
> **quiero** abrir desde la pantalla de inicio la lista de sucursales participantes,  
> **para** saber en qué tiendas puedo comprar para participar.

## Criterios de aceptación

**CA1. Abrir la lista**  
**Dado** que estoy en la pantalla de inicio,  
**cuando** presiono el enlace de sucursales participantes,  
**entonces** se abre en una pestaña externa el documento con la lista de sucursales.

**CA2. Enlace no disponible**  
**Dado** que el enlace externo no responde o devuelve error,  
**cuando** presiono el enlace de sucursales,  
**entonces** el sistema muestra el mensaje emergente "Error 404" y me regresa a la pantalla de inicio.

## Notas

- Métrica: la página redirige al concursante a la lista de sucursales participantes.
