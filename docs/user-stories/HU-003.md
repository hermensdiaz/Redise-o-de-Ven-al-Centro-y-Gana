# HU-003 | Consultar las bases oficiales

**Requisito de origen:** RF-003  
**Requisitos relacionados:** RF-001  
**Prioridad:** Media  
**Estimación (sugerida):** 1 punto

## Historia

> **Como** concursante,  
> **quiero** abrir las bases, términos y condiciones de la campaña,  
> **para** conocer las reglas legales antes de participar.

## Criterios de aceptación

**CA1. Abrir las bases**  
**Dado** que estoy en la pantalla de inicio,  
**cuando** presiono "Ver bases",  
**entonces** se abre en una nueva pestaña el documento con las bases oficiales y puedo regresar a la aplicación.

**CA2. Ventana bloqueada o error**  
**Dado** que el navegador bloquea la ventana emergente o el enlace falla,  
**cuando** presiono "Ver bases",  
**entonces** el sistema me indica que habilite las ventanas emergentes o lo intente de nuevo.

## Notas

- Las reglas que la aplicación muestra en la trivia ("No hay límite de tiempo" y volver a intentarlo con otro ticket) deben coincidir con estas bases (RF-012, RF-015).
- Métrica: la página redirige al concursante al documento de Términos, Condiciones y Bases Legales.
