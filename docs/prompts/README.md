# Registro de prompts

Este registro reúne los prompts que el equipo le dio a un agente de IA (Claude) para trabajar en este repositorio, junto con el resultado de cada uno. Sirve para la trazabilidad: muestra qué se pidió, cuándo, en qué rama y qué cambios produjo.

## Convenciones

- Cada prompt tiene su propio archivo, numerado en orden cronológico: `NN-tema-del-prompt.md`.
- El texto del prompt se copia **tal como se escribió**, sin corregir ortografía ni redacción.
- Cada archivo incluye la fecha y hora, la categoría, la rama, el commit, los archivos modificados y el resultado.

## Cómo agregar un prompt nuevo

1. Crea el archivo `NN-tema.md` con el siguiente número disponible.
2. Copia la plantilla de cualquier archivo existente y llena la tabla, el prompt textual y el resultado.
3. Agrega una fila al **Índice** y el enlace en **Por categoría**.

> **Alcance:** aquí están los prompts del 31 de octubre de 2026 de tres chats: "Renombrar carpetas a inglés" (prompts 30 a 32, de 09:47 a 09:51), en el que se renombraron a inglés las carpetas del repositorio en `main` y en `segunda-entrega`; "Revisión y rediseño de la segunda entrega" (prompts 06 a 29, de 10:22 a 16:44), en el que se revisó el repositorio contra la lista de cotejo, se rediseñaron las interfaces en Figma, se actualizaron los requisitos, las historias de usuario y el diagrama de casos de uso, y se preparó la presentación; y "Comentarios y feedback" (prompts 01 a 05, de 19:27 a 19:54), con el que se dieron los últimos retoques a la rama `segunda-entrega`. No se registran los mensajes en los que se pidió agregar los prompts de cada chat al registro. Los prompts de otras sesiones o de otras herramientas se pueden agregar con el mismo formato.
