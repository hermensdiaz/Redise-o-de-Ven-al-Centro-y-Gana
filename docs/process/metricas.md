# Métrica de Contribución Individual

## Método

Cada integrante se mide sobre un 100%, con respecto a las contribuciones que le fueron asignadas:

**% de contribución:** contribuciones completadas entre contribuciones asignadas por cien.

**Issues Resueltos:** número de issues en el repositorio asociados a esa persona como un respaldo cuantitativo.
